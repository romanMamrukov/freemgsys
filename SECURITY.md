# Security Policy

## Supported use

This repository is currently a demonstration or prototype unless its README explicitly states otherwise. It is not approved for storing real personal, financial, credential, customer, or production business data.

Only the latest default-branch version is considered for security corrections. No formal security-support SLA is provided.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is enabled for this repository.

If private reporting is unavailable, open a public issue containing only:

- the affected component;
- the general impact;
- a request for a private reporting channel.

Do not publish exploit code, secrets, personal data, customer records, tokens, credentials, or detailed reproduction steps in a public issue.

## Demo credentials and data

Any credentials shown in documentation or the interface are demo-only. They must never be reused in a production deployment. Use synthetic data when testing.
